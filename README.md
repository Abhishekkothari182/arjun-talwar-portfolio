# Arjun Talwar — Portfolio

A one-page portfolio site built with plain HTML, CSS and JavaScript (no build step).

## Files
- `index.html` — page content. Search for `EDIT:` comments and `[brackets]` to fill in real details.
- `styles.css` — theme. Colours live in the `:root` variables at the top.
- `script.js` — mobile menu, service tabs, scroll animations.

## View locally
Open `index.html` in a browser.

## Publish
Enable GitHub Pages: repo **Settings → Pages → Deploy from branch → `main` / root**.
